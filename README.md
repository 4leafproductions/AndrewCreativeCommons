This project was built with [Next.js](https://nextjs.org/) and showcases Andrew's skillset in full-stack web engineering and integrations wtih third party providers.
## Project Features
- The front end elements are reactive and display well on any device and built using React JS.
- The react framework supports a high degree of reusability on front-end elements. The tutorial feature uses a custom react component which takes another component as a parameter, allowing any element to utilize the on-hover tutorial effects without modifying each component.
- The Next framework manages callouts to NPR's RSS feeds to provide the latest posting from NPR.
- A heroku app serves as a proxy to avoid any CORS violations in the connection to NPR.
- The embedded PDF reader is supported by desktop only on most browsers. This is a browser limitation, and media queries are utilized to handle this limitation gracefully.
